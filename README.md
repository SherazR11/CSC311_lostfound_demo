Campus Lost & Found application built using Java and Spring Boot

By Sheraz Rahim

User can create an account; Sign in and out; View and Report Items to find.

To Run

once you run intelliJ, 

open window search http://localhost:8080

you will come to login signup page, you then either create your account orif you have already made one repeat the username
and password.
Once you have enter you will see the "Found something?" page and you can there type what it is and where you found it once 
entered click report item and at the top you will tehn see your item with its location.
